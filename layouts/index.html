What is disclose.io?

disclose.io is open infrastructure for safer vulnerability disclosure. Security teams can create policy and security.txt files, researchers can find official reporting channels, and both sides can use a lawyer-reviewed safe-harbor framework. The project also maintains open directories of disclosure programs and bug bounty platforms, plus public data and tools for coordinated disclosure.
